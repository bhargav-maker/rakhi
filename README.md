# Raksha Bandhan 2026

A beautiful, interactive digital celebration of Raksha Bandhan with personalized sister cards, animations, and festive confetti effects.

## 🎉 Overview

An elegant web application celebrating the sacred bond of Raksha Bandhan with 16 personalized sister profiles. Features smooth 3D card flipping animations, horizontal scrolling carousel, interactive rakhi visualization, and festive confetti celebrations triggered on every interaction.

## ✨ Features

- 🎨 **3D Card Flip Animation** - Smooth perspective-based card transitions
- 👯 **16 Sister Profiles** - Personalized messages and tags for each sister
- 📱 **Horizontal Carousel** - Swipeable sister selection with snap scrolling
- ✨ **Confetti Celebration** - Interactive festive particle effects
- 🌟 **Golden Aesthetic** - Premium luxury-inspired design with gold gradients
- 🎭 **Animated Rakhi** - Interactive 3D SVG rakhi with pulsing animations
- 💫 **Ambient Effects** - Floating gold dust particle canvas background
- 🏙️ **Responsive Design** - Optimized for mobile, tablet, and desktop
- ⚡ **Zero Dependencies** - Pure HTML, CSS, and JavaScript (except confetti.js)
- 🔄 **Persistent Interactions** - Smooth state management for card selections

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or build tools required!

### Installation

1. Clone the repository:
```bash
git clone https://github.com/bhargav-maker/rakhi.git
cd rakhi
```

2. Open in browser:
```bash
# Option 1: Direct
- Double-click index.html

# Option 2: Local server (Python 3)
python -m http.server 8000
# Then visit: http://localhost:8000

# Option 3: Node.js
npx http-server
```

## 📖 Usage

### Viewing Sister Cards
1. Scroll horizontally through the carousel to browse all 16 sisters
2. Click on any sister card to reveal her personalized greeting
3. Read the special message and heartfelt wishes
4. Enjoy festive confetti celebrations!

### Interactions
- **Tap Sister Card** → Flip to greeting card view
- **Click Rakhi** → Trigger confetti particles
- **Tap "Celebrate with Sparks"** → Launch ultimate festive celebration
- **Tap "Back to Sisters"** → Return to carousel view

## 🛠️ How It Works

- **Frontend Only** - Entire application runs in the browser
- **Canvas Background** - Ambient gold particle effects using canvas API
- **3D Transforms** - CSS 3D perspective for card flipping
- **Confetti Library** - CDN-based canvas-confetti for celebrations
- **Responsive Units** - CSS clamp() for fluid typography
- **Safe Areas** - iOS notch and safe-area awareness

## 🎨 Design Highlights

- **Color Scheme**: Gold (#FFD700), Dark Navy (#050508), Warm Accents
- **Typography**: Cinzel Decorative (headings), Cinzel (UI), Cormorant Garamond (body)
- **Effects**: Gradient animations, blur effects, drop-shadow filters
- **Borders**: Golden gradient borders with custom filigree corners
- **Accessibility**: High contrast, touch-friendly sizing, safe-area-inset

## 📊 Tech Stack

- **HTML5** - Semantic structure with SVG graphics
- **CSS3** - Advanced features:
  - CSS Grid & Flexbox
  - 3D Transforms (transform-style: preserve-3d)
  - Custom animations & keyframes
  - CSS clamp() for responsive typography
  - Gradient animations
  - Filter effects
- **Vanilla JavaScript** - No frameworks:
  - DOM manipulation
  - Event handling
  - Canvas particle system
  - State management
- **Libraries**:
  - canvas-confetti (CDN) - Celebration effects
  - Google Fonts - Premium typography
